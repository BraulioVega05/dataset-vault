# dataset-vault
A personal vault of datasets for coding, analysis, and experimentation.

This repository contains datasets that I create, clean, organize, or prepare for programming, data analysis, and data science projects.

Each folder may include:
- The dataset file
- A short description
- Data source information
- Cleaning or preprocessing notes
- Possible use cases
